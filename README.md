# JavaScript Mastery Path

A free, structured, module-wise JavaScript training program — entry level to master level, with runnable code in every module and a hands-on project at the end of each level.

**Live site:** https://learnmasterypath.com/javascript-mastery-path/

## Contents

- **Level 1 · Entry** — language foundations
- **Level 2 · Intermediate** — idiomatic, async-aware JavaScript
- **Level 3 · Advanced** — Node.js, APIs, TypeScript, tooling
- **Level 4 · Master** — production systems & architecture

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
